Kesimpulan Perjalanan Belajar Data Science (Pertemuan 1–7)

Selama tujuh pertemuan pertama, saya mempelajari fondasi penting dalam Data Science. Pembelajaran dimulai dari pengenalan konsep Data Science, siklus proyek CRISP-DM, serta peran Data Scientist dalam industri. Selanjutnya saya mempelajari Python sebagai bahasa utama Data Science, termasuk penggunaan NumPy dan Pandas untuk manipulasi data.

Pada tahap berikutnya, fokus pembelajaran beralih ke kualitas data melalui proses data cleaning, penanganan missing values, duplikasi data, dan outlier. Setelah data siap digunakan, saya mempelajari teknik visualisasi menggunakan Matplotlib dan Seaborn untuk mengubah data menjadi informasi yang mudah dipahami.

Pertemuan keenam memperkenalkan tahapan preprocessing data seperti encoding, feature scaling, dan train-test split yang menjadi fondasi Machine Learning. Pada Pertemuan ketujuh, saya mulai membangun model Machine Learning menggunakan Regresi Linear, memahami konsep supervised learning, cost function, evaluasi model menggunakan MAE, RMSE, dan R², serta membuat pipeline prediksi end-to-end menggunakan scikit-learn.

Secara keseluruhan, tujuh pertemuan ini memberikan pemahaman yang kuat mengenai alur kerja Data Science dari data mentah hingga menghasilkan model prediktif yang dapat digunakan untuk membantu pengambilan keputusan berbasis data.
